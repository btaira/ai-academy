Decode a new paper

Runs the same five extraction passes as tools/decode-paper.mjs, in this browser, using your own key. This page can't write to the repo, so when it's done you'll download the record and an updated index — drop both into src/papers/data/ and commit.

Fetched directly from arxiv.org. If your browser blocks the cross-origin request, download the PDF yourself and use "upload pdf" instead.

Records live in src/papers/data/ as JSON, one file per paper, versioned in git. Add one from the button above, with node tools/decode-paper.mjs <file-or-arxiv-id>, or with the /decode-paper command in Claude Code.
